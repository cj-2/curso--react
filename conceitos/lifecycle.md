# Lifecycle Methods

Link da documentação sobre os cliclos de vida aqui [aqui!](https://pt-br.reactjs.org/docs/state-and-lifecycle.html)

Diagaram do ciclo de vida [aqui!](https://projects.wojtekmaj.pl/react-lifecycle-methods-diagram/)

Como no Vue.js também existem um ciclo de vida nos componentes React.

```jsx
// Quando o componente é montado.
componentDidMount() {...}

// Quando o componente é atualizado.
componentDidUpdate() {...}

// Quando o componente é destruido.
componentWillUnmount() {...}
```
